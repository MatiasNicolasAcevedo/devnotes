# Notas en pestañas · referencia visual

Maquetas aprobadas por el dueño el 2026-11-28 para [S-118](../../../docs/specs/S-118-notes-tabs.md). Sirven para que cualquier agente vea el diseño sin abrir el lienzo de Claude. El contrato es la spec: si una imagen y la spec se contradicen, vale la spec (sección «Diferencias con las maquetas»).

Todo el contenido de las imágenes es ficticio. Tema oscuro actual de MUI: fondo `#181a1b`, superficies `#212324`, divisor `#393d42`, texto `#e1e3e6`, ámbar `#ffb74d` para la pestaña activa y «Guardar versión», azul `#8ab4f8` para acciones y foco, rojo `#ff6b6b` para Demo y `#ff8a80` para eliminar. Editor en Roboto Mono 14 px.
